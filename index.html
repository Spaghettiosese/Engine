Three tools, one engine

The Studio edits, the Viewer previews, and games load the same JSON the Studio saves. Nothing is baked into a mesh file, so every part stays a live shape you can reshape later.

Engine API ↓

  • WebGL2 renderer: PBR, soft PCF sun shadows, HDR bloom, ACES tone mapping, MSAA
  • 13 procedural materials (plaid, denim, leather, felt, skin, wood, metal…), bump-mapped in the shader
  • 12 parametric shapes and 12 non-destructive modifiers
  • GPU skinning with automatic weights, spring bones, two-bone IK
  • Clip mixer with phase-synced crossfades and root motion
  • Exports glTF 2.0 (.glb) with skin and animations, plus OBJ

Studio Open ↗

  • Blender layout: outliner, properties tabs, dope sheet, status bar
  • Blender hotkeys: G / R / S with X Y Z and typed values, Shift A, Tab, I, numpad views
  • Object and Pose modes, auto-keying, onion skins, undo history
  • Motion Synth: generate walk, swagger, sneak, jog, crawl or idle cycles from sliders
  • Bind any mesh into a character as a new part

Viewer Open ↗

  • Crossfade between clips and watch the blend weights live
  • Roam with root motion, or take control with WASD (Shift runs, C crawls)
  • Skeleton, onion skin, wireframe and toon overlays
  • Footstep events kick up dust; spring bones swing the bandana and holster

Use it in a game

No build step and no dependencies. Import the engine as ES modules and load a character the Studio saved.

import { Renderer, Scene, Camera, Character, runLoop } from './src/engine/index.js';

const renderer = new Renderer(document.querySelector('canvas'));
const scene = new Scene(), camera = new Camera();
const cowboy = await Character.fromURL('assets/cowboy.json');
scene.add(cowboy);
cowboy.play('Walk');                         // crossfades from whatever was playing

runLoop((dt) => {
  if (keys.shift) cowboy.play('Run', { fade: 0.3 }); // feet stay in step (sync group)
  cowboy.update(dt);
  renderer.render(scene, camera);
});
